# HH.ru — помощник откликов (тестовая сборка)

Windows-приложение открывает новую вкладку в вашем обычном Google Chrome,
ищет выбранную профессию, при удалённом поиске убирает регион, иначе использует выбранный регион и последовательно
обрабатывает вакансии на всех страницах выдачи, переходя на следующую после завершения текущей.

## Установка и запуск

1. Запустите `install.bat` один раз.
2. Запустите `run.bat`.
3. Выберите «Инженер ПТО» или добавьте профессию кнопкой «Добавить».
   Список сохраняется в `data/professions.json` и доступен после перезапуска.
   Настройте «Удалённо» и заполните сопроводительное письмо.
   Если «Удалённо» выключено, справа доступен выбор региона: Москва, Санкт-Петербург,
   Самара, Тольятти или все регионы. При удалённом поиске этот выбор игнорируется.
   Укажите собственный лимит успешных откликов за запуск — любое целое число больше нуля.
   Кнопка «Сохранить» сохраняет письмо под выбранным названием; выпадающий список рядом
   загружает сохранённые письма при последующих запусках. Письма хранятся в `data/letters.json`.
   Последнее выбранное письмо автоматически выбирается и загружается при открытии приложения.
4. Выберите площадку hh.ru в правом верхнем углу; Авито пока отключено.
   Браузер всегда Google Chrome. Нажмите «Запустить», при необходимости войдите в hh.ru вручную.
5. Если приложение покажет «Требуется действие», выполните указанное действие в браузере
   и нажмите «Продолжить» в приложении.

Для обычного Chrome установите наше расширение из папки `chrome-extension` и нажмите
«Подключить Chrome» в приложении. Полная инструкция — `chrome-extension/INSTALL.md`.
Расширение ChatGPT не нужно. Новая рабочая вкладка использует авторизацию вашего профиля
Chrome и остаётся открытой после завершения. Выбор Edge из интерфейса удалён.
Письмо копируется в системный буфер обмена перед вставкой: прежнее содержимое буфера заменяется.
История учитывает только отклики, подтверждённые надписью hh.ru в карточке вакансии.
Если результат неясен, приложение ждёт ручной проверки и не отправляет повторный отклик автоматически.
После начала финальной отправки повторное нажатие блокируется до конца текущего запуска,
даже после «Продолжить». При повреждении истории запуск блокируется, исходный файл не перезаписывается.
Повреждённый файл писем сохраняется в резервную копию `letters.json.damaged-*`; приложение
открывается с пустым списком и предупреждением в журнале.

Это чистая копия: личные данные, ключи, профили браузеров и установленные зависимости
не включены. Нужен Python 3.12+ и установленный выбранный браузер.
Сначала запустите `install.bat`, затем `run.bat`. При первом подключении Chrome
будет создан ваш собственный случайный ключ; используйте расширение из этой копии.

## Проверки

`.venv\\Scripts\\python.exe -m unittest discover -s tests -v`

Браузерные тесты используют локальные макеты форм, не отправляют реальные отклики.
Работа с авторизованным hh.ru требует первого контролируемого прогона пользователем.

История хранится локально в `data/applications.json`. Профиль Edge — в
`data/edge-profile`. Chrome использует ваш обычный профиль через расширение.
Старая папка `data/chrome-profile`, если она есть, больше не используется и не удаляется автоматически.
История откликов общая для обоих браузеров.

## Ограничения тестовой версии

- Обрабатываются все страницы до конца выдачи, достижения лимита или нажатия «Остановить».
- Между откликами выдерживается случайная пауза 5–10 секунд.
- Загрузка страницы ожидается без общего таймаута; кнопка «Остановить» прерывает ожидание.
- CAPTCHA, запрос видимости резюме и неизвестные формы требуют ручного действия.
- Разметка hh.ru меняется; при изменении кнопок/форм могут потребоваться новые селекторы.
