# Подключение обычного Google Chrome

1. Откройте приложение через `run.bat` и нажмите **Подключить Chrome**. Ключ скопируется.
2. В вашем обычном профиле Chrome откройте `chrome://extensions`.
3. Включите **Режим разработчика** (справа сверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку `chrome-extension` этого проекта.
5. Нажмите значок пазла на панели Chrome, откройте **HH.ru помощник — локальное подключение**.
6. Вставьте ключ и нажмите **Подключить**. Должно появиться сообщение о подключении.
7. В приложении выберите Google Chrome и нажмите **Запустить**.

Откроется новая вкладка в этом профиле Chrome. Приложение работает только в созданной
рабочей вкладке hh.ru; другие вкладки не меняет. В конце вкладка остаётся открытой.
При смене профиля Chrome установите и подключите расширение именно в нужном профиле.
Не подключайте одновременно несколько профилей к одному приложению.

Расширение не читает пароли или cookies. Оно видит содержимое рабочей страницы hh.ru
и передаёт карточки вакансий локальному приложению на `127.0.0.1:8765` с проверкой подписей.
Ключ не публикуйте. Удаление/отключение расширения прерывает подключение.

После обновления приложения обновите расширение кнопкой перезагрузки на
`chrome://extensions` и перезапустите приложение. Старое расширение с новым
защищённым протоколом несовместимо. Сохранённый ключ менять не требуется.

Соединение использует взаимную проверку HMAC-SHA256: ключ не передаётся по сети,
подписываются запросы и ответы, повторные и просроченные запросы отклоняются.
Одновременно допускается один активный профиль. Это не шифрование трафика и
не защита от вредоносной программы, которая уже может читать ваши файлы или
память браузера. Не публикуйте папку `data` и хранилище расширения.
Никакие внешние серверы расширения не используются.

После изменения кода расширения нажмите **Обновить** на его карточке в `chrome://extensions`.
